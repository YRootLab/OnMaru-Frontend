# 한국관광공사 Sorimaru (오디) API 상세 분석 & 온마루 카테고리 큐레이션 기획서 🇰🇷

본 문서는 **한국관광공사 관광지 오디오 가이드(Sorimaru) API**의 전수 데이터 호출 결과와, 온마루 서비스의 브랜드 아이덴티티(**한옥, 정(情), 전통시장, 고풍스러운 온기**)를 결합한 오디오 카테고리 기획 분석서입니다.

## 1. Sorimaru API 전체 데이터 구조 및 특성

- **서비스명**: 한국관광공사 관광지 오디오 가이드 정보 (Sorimaru)
- **전체 데이터 규모**:
  - 🏛️ **관광지 (`themeBasedList`)**: 총 **2,264개**
  - 🎧 **이야기/오디오 (`storyBasedList`)**: 총 **6,524개**
- **데이터 분류 메커니즘**:
  - API 원본의 `themaCategory` 필드는 공공데이터 특성상 대부분 미분류(비어있음) 상태로 응답됩니다.
  - 따라서, 실제 데이터를 정확하게 분류하고 필터링하려면 `themeSearchList` 및 `storySearchList` 오퍼레이션의 `keyword` 파라미터를 기반으로 쿼리하는 방식이 **100% 가장 확실하고 정확**합니다.

## 3. 🏠 온마루 브랜드 아이덴티티 중심 추천 카테고리 구성안

온마루의 주 아이덴티티인 **[한옥]**, **[정(情)]**, **[전통시장]**, **[조선 전통 건축과 역사]**를 극대화할 수 있도록 다음과 같이 **7대 핵심 카테고리 분류안**을 제안합니다.

```
[ 전체 ] ── [ 한옥/고택 ] ── [ 전통시장/장터 ] ── [ 마을/골목길 ] ── [ 궁궐/역사 ] ── [ 소리/문화 ] ── [ 자연/둘레길 ]
```

### 1) 🏠 `한옥/고택` (추천 1순위)
- **개념**: 바람이 머무는 한옥과 세월을 품은 종택, 선비의 고택 이야기
- **매핑 데이터**: `한옥`(19개) + `고택`(21개) + `생가`(33개) = **총 73개 오디오 스토리**
- **대표 오디오**: 남산골 한옥마을, 전주 한옥마을, 안동 하회마을 하동고택/작천고택, 북촌댁

### 2) 🏪 `전통시장/장터` (추천 2순위 — 사람의 온기 '정')
- **개념**: 사람 냄새 가득하고 정겨운 흥정이 오가는 장터 이야기
- **매핑 데이터**: `시장`(126개) + `전통시장`(10개) + `장터`(8개) = **총 144개 오디오 스토리**
- **대표 오디오**: 서울 남대문시장, 부산 국제시장, 중앙전통시장, 홍성 장터길

### 3) 🏮 `마을/골목길` (추천 3순위 — 고즈넉한 골목 탐방)
- **개념**: 고즈넉한 한옥 골목과 이웃의 정이 살아있는 정겨운 마을 이야기
- **매핑 데이터**: `마을`(230개) + `골목`(45개) = **총 275개 오디오 스토리**
- **대표 오디오**: 북촌 한옥골목, 전주 한옥마을 골목, 대구 근대문화골목, 슬로시티 마을

### 4) 🏯 `궁궐/역사` (추천 4순위 — 단청과 전통 건축)
- **개념**: 조선 500년 왕실의 서사, 웅장한 전각과 단청의 아름다움
- **매핑 데이터**: `궁`(205개) + `역사/유적`(236개) = **총 441개 오디오 스토리**
- **대표 오디오**: 경복궁 근정전/영제교, 창덕궁 후원, 덕수궁 석조전, 창경궁

### 5) 🥁 `소리/문화` (추천 5순위 — 우리 풍류와 예술)
- **개념**: 판소리, 전통주, 공예 등 한국 전통 예술과 풍류의 소리
- **매핑 데이터**: `소리`(24개) + `전통/공예`(58개) + `박물관`(193개) = **총 275개 오디오 스토리**
- **대표 오디오**: 전주 소리문화관, 전주 전통술박물관, 성덕대왕 신종 소리 해설

### 6) 🌿 `자연/둘레길` (추천 6순위 — 고즈넉한 자연 감상)
- **개념**: 숲길과 바람, 사계절의 아름다움이 흐르는 자연과 둘레길
- **매핑 데이터**: `길/둘레길`(304개) + `공원`(314개) = **총 618개 오디오 스토리**
- **대표 오디오**: 제주 올레길, 한양도성 둘레길, 숲길 오디오 가이드

## 4. UI 적용 및 사용자 경험 반영 가이드

1. **기존 섹션 4 레이아웃 완전 유지**:
   - `CategoryTagFilter` 카테고리 태그 칩 부분에 위 **6대 큐레이션 태그 (`한옥/고택`, `전통시장/장터`, `마을/골목길`, `궁궐/역사`, `소리/문화`, `자연/둘레길`)**를 깔끔하게 적용하였습니다.
2. **자연스러운 딜레이 없는 필터링**:
   - 태그를 클릭하면 Sorimaru API의 실제 데이터 키워드 쿼리가 자동으로 연동되어, 각 주제에 맞는 실제 한국관광공사 오디오 해설 및 대본이 부드럽게 필터링됩니다.
