# 온마루

**온마루는 전국의 한옥과 그곳에 깃든 이야기, 소리, 여행 경험을 하나의 디지털 여정으로 연결하는 문화유산 탐험 플랫폼입니다.**

사용자는 지도를 따라 한옥을 발견하고, 장소의 배경과 지역의 맥락을 읽고, 오디오 도슨트로 이야기를 들으며, 자신만의 방문 기록을 쌓을 수 있습니다. 온마루는 전통 건축을 단순한 관광 정보가 아니라 현재의 여행자가 직접 경험하고 기록하는 문화 공간으로 전달합니다.

## 서비스가 해결하는 경험

한옥과 문화유산 정보는 지역·기관·콘텐츠 형태에 따라 흩어져 있어, 여행자가 한 번의 흐름으로 발견하고 이해하고 기록하기 어렵습니다. 온마루는 다음 경험을 하나의 서비스 안에서 제공합니다.

- **발견**: 관심사와 여행 의도에 맞는 한옥·지역·문화 콘텐츠를 찾습니다.
- **이해**: 건축, 역사, 생활문화, 지역 이야기를 읽고 듣는 방식으로 만납니다.
- **탐험**: 지도에서 장소와 다른 여행자의 경험을 살피며 다음 방문지를 고릅니다.
- **기록**: 저장, 후기, 방문 인장, 개인 타임라인을 통해 나만의 한옥 여정을 축적합니다.

## 핵심 사용자 경험

### 1. 여정 큐레이션

홈 화면은 사용자의 관심사와 탐험 목적에서 출발합니다. 추천 코스, 인기 한옥 소리, 인기 지역을 통해 탐험의 출발점을 제시하고, 여행자가 선택한 조건에 맞는 여정 제안을 제공합니다. 별도의 탐색 화면으로 분산하지 않고 홈에서 바로 여정을 시작하도록 설계했습니다.

### 2. 한옥도감

한옥도감은 전국의 한옥과 문화유산을 탐색하는 아카이브입니다. 지역·유형·주제에 따라 살펴보고, 장소마다 건축적 특징과 문화적 맥락을 읽을 수 있습니다. 정보가 충분하지 않거나 외부 데이터 응답이 불안정한 상황에서도 사용자가 맥락을 잃지 않도록 안내 경험을 유지합니다.

### 3. 소리마루 오디오 도슨트

소리마루는 한옥과 문화유산의 이야기를 오디오로 경험하는 도슨트 서비스입니다. 장소별 음성 콘텐츠, 대본, 현장 이미지와 위치 맥락을 결합해 이동 중에도 문화유산 이야기를 들을 수 있습니다. 재생 중인 이야기와 연관된 장소·콘텐츠를 이어 보며 탐험을 확장할 수 있습니다.

### 4. 한옥 지도와 온기 이야기

지도는 한옥마을, 고택, 문화 장소를 공간적으로 탐색하는 중심 화면입니다. 여행자가 남긴 방문 경험과 후기를 ‘온기 이야기’로 모아 장소의 정량 정보만으로 알기 어려운 분위기와 체험의 결을 전달합니다. 관심 장소를 저장하고, 로그인 후에는 자신의 활동과 연결해 관리할 수 있습니다.

### 5. 수결첩

수결첩은 전국 한옥 방문 경험을 모으는 디지털 인장첩입니다. 방문한 장소의 인장을 수집하고, 권역별 탐방 현황과 나만의 기록을 한눈에 확인할 수 있습니다. 단발성 방문을 계속 이어지는 문화 탐험으로 전환하는 장치입니다.

### 6. 개인화된 마이페이지

로그인 사용자는 저장한 장소, 여정, 오디오 콘텐츠, 방문 기록과 활동 타임라인을 한곳에서 확인합니다. 저장과 기록은 여러 화면에서 일관되게 이어지며, 사용자는 자신의 한옥 탐험 이력을 관리할 수 있습니다.

## 주요 화면과 역할

| 화면 | 역할 |
| --- | --- |
| 홈 | 여행 의도 기반 탐험 시작, 추천 콘텐츠, 여정 큐레이션 |
| 한옥도감 | 전국 한옥·문화유산 아카이브 탐색과 상세 맥락 확인 |
| 소리마루 | 문화유산 오디오 도슨트 재생, 대본·장소·관련 콘텐츠 탐색 |
| 지도 | 장소 탐색, 온기 이야기 확인, 저장과 지역별 탐험 |
| 수결첩 | 방문 인장 수집, 권역별 탐방 기록과 도감 관리 |
| 마이페이지 | 저장한 여정·장소·소리와 개인 활동 타임라인 관리 |
| 운영 화면 | 콘텐츠 큐레이션, 사용자·후기·신고 상태 확인을 위한 관리 기능 |

## 콘텐츠와 데이터의 흐름

온마루는 공공·문화 데이터, 자체 큐레이션, 사용자 활동 데이터를 함께 활용합니다. 외부 데이터는 한옥·문화유산·지역 탐색의 기반이 되고, 서비스 큐레이션은 여행 맥락과 이야기 흐름을 보강합니다. 사용자가 남긴 저장·방문·후기는 개인 경험을 만드는 동시에 장소를 발견하는 데 도움이 되는 사회적 맥락이 됩니다.

백엔드와의 연동은 여정 생성, 장소 저장, 지도 후기, 개인 타임라인, 인증 상태를 중심으로 확장하고 있습니다. 일부 데이터 연동은 단계적으로 고도화 중이며, 응답 실패나 데이터 공백이 발생해도 사용자가 빈 화면을 마주하지 않도록 대체 안내와 재시도 경험을 제공합니다.

## 다른 개발팀을 위한 협업 범위

온마루 프론트엔드는 다음과 같은 협업을 염두에 두고 운영합니다.

- **백엔드 팀**: 여정 추천, 장소·후기·저장 데이터, 사용자 활동 타임라인, 인증 및 요청 보안 계약을 함께 정의합니다.
- **콘텐츠·큐레이션 팀**: 한옥 설명, 지역 스토리, 오디오 도슨트, 이미지와 태그의 품질 및 노출 순서를 관리합니다.
- **디자인 팀**: 전통 소재를 현대적인 탐험 경험으로 전달하는 화면 체계, 접근성, 모바일 반응형 경험을 함께 고도화합니다.
- **운영 팀**: 사용자 후기·신고·콘텐츠 상태를 관리하고, 노출 기준과 품질 정책을 유지합니다.

협업 시에는 화면 구현 세부나 내부 소스보다 사용자 시나리오, API 계약, 콘텐츠 기준, 운영 정책을 우선 공유합니다. 비공개 저장소, 인증 정보, 토큰, 개인 키 및 환경 설정 값은 문서나 외부 대화에 포함하지 않습니다.

## 서비스 운영 원칙

- 한옥과 문화유산을 고정된 전시물이 아닌, 여행자가 현재형으로 경험하는 이야기로 다룹니다.
- 정보가 부족하거나 연결이 지연돼도 사용자가 탐험의 흐름을 잃지 않도록 안내합니다.
- 저장·후기·방문 기록은 로그인 상태와 개인정보 보호 원칙을 전제로 처리합니다.
- 애니메이션과 인터랙션은 콘텐츠 이해를 돕는 범위에서 사용하며, 이동 감소 설정을 존중합니다.
- 운영 기능은 일반 사용자 경험과 분리하고, 콘텐츠와 사용자 활동의 신뢰성을 우선합니다.

## 문의와 협업 제안

서비스 연동, 콘텐츠 제휴, 데이터 협업 또는 운영 논의가 필요한 팀은 담당 채널을 통해 목적, 대상 사용자, 필요한 데이터 범위, 기대 일정과 함께 문의해 주세요. 구현 소스나 인증 정보 대신 서비스 요구사항과 계약 가능한 인터페이스를 기준으로 협업을 진행합니다.
