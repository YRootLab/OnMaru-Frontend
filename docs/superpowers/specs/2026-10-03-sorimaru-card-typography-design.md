# 소리마루 카드 타이포그래피 개선 설계

## 목표

`오늘, 여기에서` 캐러셀과 `소리로 만나는 한국` 아카이브 카드의 작은 글자를 읽기 쉽게 한 단계 키운다. 긴 이야기 제목은 말줄임 한 줄 대신 최대 두 줄까지 보여 주고, 위치 기반 안내 문장은 핵심 조건과 대체 콘텐츠만 강조한다.

## 적용 범위

- `StoryCarousel`의 주변 이야기 카드
- `SorimaruArchiveBrowse`의 이야기별 카드
- `SorimaruAudioFeature`의 위치 기반 안내 문장
- 두 카드 유형의 로딩 스켈레톤

장소별 아카이브 보기, 필터, 검색창, 페이지네이션, 카드 크기 외의 레이아웃은 변경하지 않는다.

## 시각 규칙

### 카드 타이포그래피

- 카드 제목, 부제, 카테고리, 위치, 설명, 재생 시간과 출처처럼 현재 작게 표시되는 텍스트를 기존 계층에서 각각 한 단계 키운다.
- 제목은 `line-clamp: 2`를 사용해 최대 두 줄까지 표시한다.
- 제목이 한 줄이어도 카드 내 정보 순서와 정렬은 유지한다.
- 두 줄 제목이 다른 메타데이터를 덮지 않도록 카드의 최소 높이와 내부 여백을 필요한 만큼만 늘린다.
- 모바일에서도 같은 두 줄 제한을 적용하되 카드 폭과 가로 스크롤 동작은 유지한다.

### 위치 안내 강조

안내 문장은 다음처럼 표시한다.

> **반경 3km** 안에는 아직 등록된 이야기가 없어요. **전국 큐레이션**을 보여드릴게요.

- 기본 문장은 라이트 모드에서 기존 중성 회색 `meok` 계열을 사용한다.
- `반경 3km`와 `전국 큐레이션`만 기존 주황색 `juhong` 계열과 강조 굵기를 사용한다.
- 다크 모드에서도 기본 문장과 강조 문장이 각각 기존 중성 회색·주황색 의미를 유지한다.
- 다른 위치 안내 문구에는 임의로 같은 강조를 적용하지 않는다.

## 로딩 상태

- 카드 높이가 커지는 만큼 각 스켈레톤도 실제 카드의 최종 높이와 제목 두 줄 영역을 동일하게 예약한다.
- 이미지 비율, 카드 폭, 열 수와 캐러셀 이동 방식은 유지한다.
- 데이터 도착 시 카드가 커지거나 아래 콘텐츠가 밀리는 레이아웃 이동이 없어야 한다.

## 구조

- 데이터 요청과 상태 관리는 변경하지 않는다.
- 위치 안내의 강조 범위는 렌더링 계층에서 명시적인 텍스트 조각으로 표현한다.
- 카드 스타일은 기존 Emotion styled component 안에서 조정하고 새 전역 스타일이나 신규 디자인 토큰은 만들지 않는다.

## 검증

- 테스트에서 위치 안내의 기본 문장과 두 강조 구간을 구분해 확인한다.
- 주변 이야기 카드와 아카이브 카드 제목이 두 줄 제한을 사용하는지 확인한다.
- 스켈레톤이 늘어난 카드와 대응하는 제목 영역 및 높이를 예약하는지 확인한다.
- 관련 테스트, 전체 타입 검사, 변경 파일 ESLint와 프로덕션 빌드를 실행한다.
- 포트 3002에서 데스크톱과 좁은 화면을 확인해 제목 두 줄, 메타데이터 간격, 강조 색상과 레이아웃 안정성을 검증한다.
