# 정보지도 홈 복귀 내비게이션 설계

## 목적

정보지도의 한옥 기본 화면에서 다른 카테고리 또는 지역 결과로 이동한 사용자가 현재 탐색 맥락을 이해하고, 이전 한옥 화면으로 예측 가능하게 복귀할 수 있도록 한다.

## 사용자 경험

- 한옥 기본 화면은 정보지도의 홈으로 취급한다.
- 한옥이 아닌 유효 카테고리 화면과 지역 결과 화면의 목록 상단에 `‹ 지도 홈으로 가기`를 표시한다.
- 기존의 `전국 · 지역명` 문구는 제거한다.
- 복귀 버튼 위에는 16px의 여백을 두어 검색·모드 헤더와 분리한다.
- 버튼을 누르면 카테고리를 `hanok`으로, 지역을 전국으로 되돌린다.
- 한옥 홈에서 이탈하기 직전의 목록 스크롤 위치, 지도 중심, 줌 단계를 복원한다.
- 저장된 복귀 지점이 없으면 한옥 전국 기본 상태로 안전하게 복귀한다.
- 상단 카테고리 칩, URL의 유효 카테고리 동기화, 정보지도 API 카테고리 계약은 유지한다.
- 온기 모드와 정보지도 밖의 홈 내비게이션은 변경하지 않는다.

## 상태와 데이터 흐름

정보지도 전용 탐색 상태에 한옥 홈 복귀 스냅샷을 둔다. 스냅샷은 목록 스크롤 위치와 지도 viewport만 포함하며 API 응답 자체를 복제하지 않는다. 한옥 홈에서 다른 카테고리 또는 지역으로 처음 진입할 때 스냅샷을 기록하고, 하위 화면 사이를 이동할 때는 덮어쓰지 않는다.

`지도 홈으로 가기`를 누르면 선택 장소와 상세 패널을 닫고, 한옥·전국 상태를 먼저 적용한 뒤 저장된 viewport와 목록 스크롤을 복원한다. URL은 기존 MapPage 동기화 경계를 통해 `category=hanok`으로 정규화한다.

## 컴포넌트 경계

- `CategoryChips`: 한옥 홈에서 다른 카테고리로 나갈 때 복귀 스냅샷 생성을 요청한다.
- `InfoPlaceList`: 하위 화면 여부를 판단해 홈 복귀 버튼을 렌더링하고 목록 스크롤 복원을 수행한다.
- 지도 탐색 상태/전용 훅: 홈 스냅샷의 저장과 소비를 담당한다.
- `MapPage`: 기존 URL category 동기화를 그대로 유지한다.

렌더링 컴포넌트가 API 호출이나 복귀 규칙을 직접 소유하지 않도록 복귀 판정과 상태 전이는 전용 훅 또는 상태 액션으로 둔다.

## 오류와 경계 조건

- 새로고침이나 직접 URL 진입처럼 스냅샷이 없으면 기본 한옥 전국 화면의 현재 viewport를 사용한다.
- 모바일과 데스크톱은 같은 복귀 규칙을 사용하되 각 목록 스크롤 컨테이너의 위치를 독립적으로 복원한다.
- 이미 한옥 전국 화면이면 복귀 버튼을 렌더링하지 않는다.
- 복귀 중 이전 카테고리의 목록·viewport 응답은 기존 요청 범위 검사와 abort 정책으로 무시한다.

## 검증

- 다른 모든 정보 카테고리에서 `지도 홈으로 가기`가 보이고 한옥 홈에서는 보이지 않는다.
- 지역 결과에서도 기존 breadcrumb 대신 동일 버튼이 보인다.
- 복귀 시 `infoCategory=hanok`, `infoRegionCode=null`, URL `category=hanok`이 된다.
- 한옥 홈의 목록 스크롤, 지도 중심, 줌이 복원된다.
- 직접 URL 진입처럼 스냅샷이 없어도 오류 없이 한옥 홈으로 이동한다.
- 온기 모드의 필터와 기존 지도 API 계약 테스트가 유지된다.
