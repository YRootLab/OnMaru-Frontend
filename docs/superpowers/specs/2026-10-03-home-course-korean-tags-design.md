# 홈 추천 코스 한국어 태그 설계

## 목표

홈 화면 `이번 주 추천 코스` 카드에 노출되는 서버 분류 코드와 콘텐츠 태그를 사용자가 이해하기 쉬운 한국어 칩으로 표시한다. API 요청에 사용하는 원본 코드와 상단 카테고리 필터 동작은 유지한다.

## 분류 라벨

화면 표시 직전에 다음 코드를 한국어로 변환한다.

| 서버 코드 | 표시 라벨 |
| --- | --- |
| `HANOK` | 한옥 |
| `HANOK_EXPERIENCE` | 한옥 체험 |
| `HANOK_CAFE` | 한옥 카페 |
| `HANOK_STAY` | 한옥 숙박 |
| `CULTURE_ART` | 문화 예술 |
| `TRADITIONAL_FOOD` | 전통 음식 |
| `GARDEN_ECOLOGY` | 정원 생태 |
| `LOCAL_SCENE` | 지역 생활 |

매핑되지 않은 영문 코드나 빈 값은 원문을 그대로 노출하지 않고 `추천 장소`로 표시한다. 이미 한국어로 전달된 분류값은 그대로 사용한다.

## 태그 구성

- 첫 번째 칩은 변환된 분류 라벨이며 항상 표시한다.
- 이후 칩은 서버 `tags` 배열에서 가져온다.
- 콘텐츠 태그 앞의 `#`은 제거하고 앞뒤 공백을 정리한다.
- 분류 라벨과 같은 태그 및 대소문자·공백 정리 후 중복되는 태그는 제거한다.
- 한 카드에서 최대 3개 칩만 표시한다. 일반 코스는 분류 칩 1개와 콘텐츠 태그 최대 2개를 표시한다.
- `savedByMe`가 참이면 `저장됨`을 마지막 칩으로 반드시 표시하고 콘텐츠 태그를 최대 1개로 줄여 `분류 + 콘텐츠 태그 + 저장됨`의 3개 제한을 지킨다.

## 시각 규칙

- 분류 칩은 기존 주황색 의미 색상을 연하게 사용한다: 밝은 주황 배경, 진한 주황 글자.
- 콘텐츠 태그와 `저장됨`은 중성 회색 배경과 회색 글자를 사용한다.
- 모든 칩은 작은 캡슐형 모서리, 한 줄 텍스트, 동일한 높이와 간격을 사용한다.
- 태그 목록은 한 줄을 유지하고 카드의 `일정 보기` CTA 영역을 침범하지 않는다.
- 다크 모드에서는 기존 `juhong`과 중성 표면 토큰을 사용해 같은 의미 계층을 유지한다.
- 카드 크기, 이미지 비율, 제목·설명 높이, 캐러셀 이동 방식은 변경하지 않는다.

## 구조

- 코드→한국어 변환과 태그 정규화·중복 제거는 결정적인 presentation helper로 분리한다.
- `JourneyDiscoveryFeed`는 helper가 반환한 표시 모델만 렌더링한다.
- API 응답 타입, repository, 요청 파라미터와 카테고리 필터 코드에는 변경을 가하지 않는다.

## 검증

- 알려진 영문 코드 8종이 정확한 한국어로 변환되는지 테스트한다.
- 알 수 없는 영문 코드와 빈 값이 `추천 장소`로 표시되는지 테스트한다.
- 이미 한국어인 분류는 그대로 유지되는지 테스트한다.
- `#` 제거, 공백 정리, 분류와의 중복 제거, 최대 3개 제한을 테스트한다.
- 카드가 분류 칩과 중성 콘텐츠 칩을 의미에 맞게 렌더링하는지 확인한다.
- 관련 테스트, 전체 타입 검사, 변경 파일 ESLint, 프로덕션 빌드와 데스크톱·모바일 화면을 검증한다.
