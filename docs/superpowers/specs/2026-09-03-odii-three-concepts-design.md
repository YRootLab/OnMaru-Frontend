# 오디 페이지 3개 디자인 콘셉트 비교 명세

## 목표

한국관광공사 오디의 문화유산 오디오와 온마루가 전하고 싶은 한국의 정을 한 화면에서 자연스럽게 연결한다. 페이지의 역할은 기능을 설명하는 것이 아니라, 방문자가 한 장소를 골라 바로 듣게 만드는 것이다. 공모전 심사에서도 기억될 하나의 상징적 경험은 대한민국 지도에서 선택한 지역의 소리가 번지는 장면이다.

## 공통 원칙

- `작은 제목 → 큰 제목 → 부연 설명`의 반복 구조를 제거한다.
- 각 섹션은 제목 하나와 필요한 경우에만 한 문장의 기능 설명을 가진다.
- `SECTION 2 · UI STUDY`, `IMPROVEMENT`, `임시 테스트` 등 제작 과정용 문구와 비교 섹션을 제거한다.
- `장면을 골라 듣다`의 주제 해시태그, 전체/테마 카테고리 칩, 지역 칩은 콘텐츠 탐색 구조이므로 유지한다. 세 줄을 동시에 노출하지 않고 사용 맥락에 맞춰 가까운 콘텐츠와 묶는다.
- `오늘, 여기에서` 섹션과 위치 사용 기능은 유지한다. 제목, 현재 위치 요약, 위치 버튼의 정보 위계만 정돈한다.
- 오디오 재생, 현재 재생 상태, 지역 선택, 북마크, API 연결은 유지한다.
- 장식용 번호, 과도한 그라데이션 제목, 무의미한 유리 효과와 흩어진 모션을 제거한다.
- 키보드 포커스, 모바일 레이아웃, `prefers-reduced-motion`을 지원한다.
- 밋밋함은 더 많은 문구나 장식으로 해결하지 않는다. 백자색 바탕에 매우 옅은 장소 사진의 빛, 섹션별 온도 차이, 얇은 경계와 선택 상태를 사용해 공간 깊이를 만든다.

## 비교 방식

세 콘셉트는 같은 데이터와 기능을 공유하되 별도 미리보기 경로에서 확인한다.

- `/odii/concepts/sori` — 소리로 듣는 한국
- `/odii/concepts/hanji` — 디지털 한지 아카이브
- `/odii/concepts/studio` — 프리미엄 오디오 스튜디오
- `/odii/concepts` — 세 안으로 이동하는 내부 비교 인덱스

메인 `/odii`는 비교가 끝나기 전까지 기존 경로로 보존한다. 다만 제작 과정용 임시 비교 섹션은 메인에서도 제거한다.

## 공통 토큰

- 백자 `#FAFAF8`: 기본 배경
- 먹 `#1D1D1F`: 제목과 핵심 컨트롤
- 돌담 `#746F68`: 보조 정보
- 오디 장미 `#F84E76`: 재생 및 선택 상태
- 온돌빛 `#FFB36B`: 소리 파동과 따뜻한 강조
- 솔잎 `#40685A`: 지도와 지역 상태

타이포 역할은 큰 감성 문장에 `MaruBuri`, 제목·본문·컨트롤에 `SF Pro Display / Apple SD Gothic Neo`, 짧은 위치·시간 정보에 같은 산세리프의 작은 유틸리티 스케일을 사용한다. 영문 대문자 라벨은 사용하지 않는다.

## 콘셉트 A — 소리로 듣는 한국

가장 균형 잡힌 공모전 출품안이다. 넓은 백자색 여백 위에 장소 사진과 한국 지도만 강하게 남긴다.

```text
한국의 마음은                 [대표 장소 이미지]
소리로 남습니다               [재생]

     [이전] [가장 큰 중앙 장면] [다음]

[선택 가능한 대한민국 지도]   [선택 지역 대표 이야기]
```

- 히어로: 한 문장의 명조체 선언과 대표 장소 재생 경험을 좌우로 배치한다.
- 두 번째 섹션: 중앙 카드를 양옆보다 14% 크게 하고, 주변 카드는 일부만 보여 다음 선택을 암시한다.
- 지도: 제주도를 포함한 인식 가능한 대한민국 실루엣과 권역 형태를 사용한다. 선택 권역에서 단 한 번의 잔잔한 음파가 번진다.
- 시그니처: 지도 위에서 장소와 소리가 연결되는 온돌빛 파동.

## 콘셉트 B — 디지털 한지 아카이브

한지 질감을 화면 전체에 덮는 흔한 전통 디자인을 피하고, 접힌 기록지와 사진 여백의 물성을 인터랙션 구조로 사용한다.

```text
[세로 기록 제목]  [겹친 사진 한 장]
                  [짧은 캡션 / 듣기]

 [작은 기록] [펼쳐진 중앙 기록] [작은 기록]

[먹선으로 그린 한국 지도]      [지역 기록 카드]
```

- 히어로: 종이 가장자리와 사진 캡션을 활용하되 문구는 한 문장만 둔다.
- 두 번째 섹션: 중앙 카드가 펼쳐진 기록물처럼 넓어지고, 좌우 카드는 접힌 상태로 남는다.
- 지도: 먹선 기반 실루엣과 장미색 낙관 형태의 선택 표시를 사용한다.
- 시그니처: 선택한 카드가 종이처럼 조용히 펼쳐지는 한 번의 전환.

## 콘셉트 C — 프리미엄 오디오 스튜디오

전통문화 사이트의 관습에서 벗어나, 사진과 재생 인터페이스를 정교하게 편집한 현대적 청음실로 표현한다.

```text
[대형 장소 사진 ----------------------]
[제목]                      [원형 재생]

[이전 장면] [선명한 중앙 앨범] [다음 장면]
             [짧은 파형]

[어두운 한국 지도]          [재생 대기열]
```

- 히어로: 화면 폭을 쓰는 장소 이미지와 짧은 제목, 하나의 재생 버튼만 둔다.
- 두 번째 섹션: 중앙 카드를 앨범처럼 크게 보이고 선택된 카드에만 최소 파형을 표시한다.
- 지도: 먹색 야간 지도에 선택 지역만 따뜻하게 켜지는 방식으로 표현한다.
- 시그니처: 재생 중인 지역과 카드에만 동기화되는 하나의 파형.

## 한국 지도 동작

- 기본 상태에서는 대한민국 전체 윤곽과 권역 경계를 조용하게 보여준다.
- 권역을 선택하면 해당 형태의 색과 접근성 상태(`aria-pressed`)가 바뀐다.
- 선택 지역의 실제 매칭 결과만 보여준다. 결과가 없을 때 다른 지역 이야기를 섞지 않고 탐색 가능한 안내를 표시한다.
- 데스크톱은 지도와 대표 이야기 패널을 나란히, 모바일은 지도 아래에 선택 지역 카드를 배치한다.
- 지역 목록은 지도와 동기화된 키보드 접근 가능한 보조 컨트롤로 제공한다.

## 구현 경계

- 공통 데이터 로딩과 스토어를 복제하지 않는다.
- 콘셉트별 차이는 히어로, 대표 장면 레일, 지도 표현 컴포넌트에 한정한다.
- 후반의 주변 이야기·아카이브·저장 기능은 공통 컴포넌트를 사용하고 제목과 설명만 간결하게 정리한다.
- 첨부 화면의 카테고리 및 지역 선택 항목과 `오늘, 여기에서`의 기능·문구는 보존하며, 배경·간격·선택 상태만 콘셉트에 맞게 정제한다.
- 새로운 대형 UI 라이브러리나 지도 런타임 의존성은 추가하지 않는다. SVG 지도와 기존 Framer Motion을 사용한다.

## 검증

- 세 미리보기 경로가 모두 렌더링되고 같은 오디오 데이터와 재생 상태를 사용해야 한다.
- 중앙 카드의 크기 차이가 데스크톱과 모바일 모두에서 명확해야 한다.
- 지도 권역을 포인터와 키보드로 선택할 수 있어야 한다.
- 선택한 지역에 결과가 없을 때 잘못된 대체 이야기를 보여주지 않아야 한다.
- TypeScript 검사, 관련 테스트, 프로덕션 빌드를 통과해야 한다.
