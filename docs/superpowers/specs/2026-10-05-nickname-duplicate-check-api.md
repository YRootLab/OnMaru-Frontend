# 닉네임 중복 확인 API 요청

## 배경

현재 프로필 수정 화면(마이페이지)에서 닉네임 글자 수 제한(2~20자)은 프론트에서 처리 중이나,
**닉네임 중복 여부는 서버 데이터가 필요하므로 별도 API가 필요합니다.**

---

## 요청 엔드포인트

```
GET /api/v1/members/nickname/check?value={nickname}
```

### 요청 파라미터

| 파라미터 | 타입   | 필수 | 설명               |
|----------|--------|------|--------------------|
| `value`  | string | ✓    | 확인할 닉네임 문자열 |

### 응답 (200 OK)

```json
{
  "available": true
}
```

| 필드        | 타입    | 설명                              |
|-------------|---------|-----------------------------------|
| `available` | boolean | `true` = 사용 가능 / `false` = 중복 |

### 에러 응답

| 상태 코드 | 설명                          |
|-----------|-------------------------------|
| `400`     | `value` 파라미터 누락 또는 형식 오류 |
| `401`     | 인증 필요 (로그인 사용자만 호출 가능) |

---

## 프론트 연동 계획

- 닉네임 input `onBlur` 시점에 호출 (디바운스 300ms)
- 결과에 따라 input 하단에 인라인 피드백 표시
  - `available: true` → "사용 가능한 닉네임이에요 ✓"
  - `available: false` → "이미 사용 중인 닉네임이에요"
- 중복이거나 확인 전이면 저장 버튼 비활성화
