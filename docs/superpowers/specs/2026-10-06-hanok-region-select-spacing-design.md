# 한옥 지역 선택 메뉴 간격 개선 설계

## 목표

한옥 페이지의 `전국 한옥 도감` 섹션에서 지역 선택 메뉴가 검색창과 같은 폭으로 과도하게 늘어나지 않게 한다. 선택 메뉴 내부는 `leading padding → 지역명 → 일정한 간격 → chevron → trailing padding` 순서를 유지해 시각적으로 균형 잡힌 컨트롤로 만든다.

## 범위

- `FilterBar`의 지역 선택 컨트롤만 수정한다.
- 검색, 지역 필터링, URL 쿼리 동기화 동작은 변경하지 않는다.
- 유형 필터, 배지 필터, 카드 레이아웃은 변경하지 않는다.

## UI 설계

- 네이티브 `select`의 접근성과 선택 동작은 유지한다.
- 브라우저 기본 화살표를 숨기고 장식용 chevron을 컨트롤 내부에 배치한다.
- 데스크톱에서는 컨트롤이 늘어나지 않도록 고정된 안정적 너비를 사용한다.
- 좌우 내부 여백은 동일하게 `16px`을 사용한다.
- 선택된 지역명과 chevron 사이는 `8px`을 사용한다.
- chevron은 `pointer-events: none`으로 설정해 select 조작을 방해하지 않는다.
- 좁은 화면에서는 검색창 다음 줄에서 전체 너비를 사용하되 같은 내부 간격을 유지한다.
- 기존 높이, 테두리, 배경색, 포커스 표시, 라이트/다크 테마는 유지한다.

## 구현 경계

`FilterBar.tsx` 내부에 지역 선택용 래퍼와 chevron 표현을 추가한다. 데이터 흐름은 기존처럼 `region` 값과 `onRegionChange` 콜백을 사용하며, 새로운 API 호출이나 비즈니스 로직은 도입하지 않는다.

## 검증

- 컴포넌트 테스트에서 지역 선택 요소와 장식용 chevron이 렌더링되는지 확인한다.
- 타입 검사와 관련 테스트를 실행한다.
- 데스크톱과 모바일 너비에서 검색창/지역 메뉴 배치, 좌우 여백, chevron 위치를 시각적으로 확인한다.
- 지역을 변경해도 필터링과 URL 쿼리 동기화가 기존처럼 동작하는지 확인한다.
