# 홈 브랜드 오로라 배경 디자인

## 목적

홈의 첫 검색 경험에 온마루의 브랜드 색을 활용한 은은한 움직임을 더한다. AWS 프리 티어 화면의 넓은 빛 번짐을 참고하되, 온마루 색 체계와 콘텐츠 구조에 맞는 고유한 분위기로 재해석한다. 기존 문구, 레이아웃, 검색 동작, 추천 카드 구조는 변경하지 않는다.

## 시각 방향

히어로 배경은 중립색을 그라디언트 재료로 사용하지 않는다. `juhong`, `hwanggeum`, `cheongrok`, `kobalt`, `jaha`의 가장 옅은 토큰을 큰 radial gradient로 겹쳐 오색의 빛이 서로 스미는 장면을 만든다. 색은 검색 콘텐츠의 대비를 해치지 않을 정도의 낮은 불투명도로 사용한다.

그라디언트 레이어는 히어로 상단과 양옆에서 보이고, 하단으로 갈수록 마스크를 통해 투명해진다. 별도의 회색이나 흰색 그라디언트를 덧대지 않고 레이어 자체가 사라지면서 기존 홈 표면이 자연스럽게 드러나도록 한다.

## 움직임

두 개의 오로라 레이어가 서로 다른 18~24초 주기로 천천히 이동한다. 이동 범위와 확대 변화는 작게 제한해 사용자가 애니메이션을 의식하기보다 살아 있는 배경으로 느끼게 한다. 스크롤과 애니메이션 진행률은 연결하지 않으며, 레이아웃과 페인트 범위를 격리한다.

`prefers-reduced-motion: reduce`에서는 애니메이션을 제거하고 동일한 색 배치의 정지 화면을 제공한다.

## 테마와 반응형

라이트 모드는 50 단계의 브랜드 색을 중심으로 사용한다. 다크 모드는 기존 남색 표면 위에 같은 다섯 계열의 낮은 투명도 광원을 배치하며 텍스트 대비를 유지한다. 모바일에서는 색 덩어리의 크기와 위치만 조정하고 레이어 수를 늘리지 않는다.

## 구성 경계

배경은 `JourneyHome`의 표현 전용 컴포넌트로 분리한다. 네트워크 요청, 상태 저장, 비즈니스 규칙은 추가하지 않는다. 검색 전 히어로에만 시각적으로 집중되며 검색 후 결과 화면과 추천 피드의 기능에는 영향을 주지 않는다.

## 검증

- TypeScript와 대상 린트를 통과한다.
- 데스크톱과 모바일의 라이트·다크 테마에서 텍스트와 검색 컨트롤의 대비를 확인한다.
- 히어로에서 추천 피드로 이어지는 경계에 색 띠나 갑작스러운 전환이 없는지 확인한다.
- 모션 감소 설정에서 모든 배경 움직임이 멈추는지 확인한다.
- 변경 전후 레이아웃의 위치와 높이가 동일한지 시각 비교한다.

## 제외 범위

타이포그래피, 문구, 카드 스타일, 검색 로직, 데이터 조회, 전역 디자인 토큰은 이번 작업에서 변경하지 않는다.
