# 지역별 한옥 스테이 페이지네이션 디자인

## 목표

지역별 한옥 스테이의 현재 7개 아코디언 구성을 유지하면서, 사용자가 앞뒤 페이지를 명확하게 탐색하도록 양방향 페이지네이션을 제공한다. 중복된 전체 건수 표시는 제거하고 지역 필터 결과 수를 필터와 가까운 곳에서 즉시 확인하게 한다.

## 정보 위계

- 섹션 제목 `지역별 한옥 스테이`를 가장 위에 둔다.
- 제목 바로 아래에 있던 단독 `80곳` 부제는 제거한다.
- 지역 필터 행의 오른쪽 끝에 현재 범위와 결과 수를 표시한다.
  - 전체 선택: `전국 80곳`
  - 지역 선택: `서울 9곳`
- 지역 필터 맨 앞에 `전체`를 추가해 전국 목록으로 돌아가는 방법을 명확하게 제공한다.
- 아코디언 아래 중앙에는 현재 페이지와 전체 페이지인 `9 / 12`만 표시한다.

## 페이지 탐색

- 한 페이지는 기존과 같은 최대 7개 숙소로 구성한다.
- 아코디언 영역의 왼쪽과 오른쪽에 이전·다음 화살표 버튼을 배치한다.
- 첫 페이지에서는 이전 버튼을, 마지막 페이지에서는 다음 버튼을 비활성화한다.
- 지역 필터가 바뀌면 첫 페이지와 첫 번째 활성 숙소로 초기화한다.
- 페이지 이동 뒤에도 현재 7개 묶음 안에서는 기존 아코디언 확장 상호작용을 유지한다.

## 모션

- 다음 페이지는 현재 묶음이 왼쪽으로 빠지고 새 묶음이 오른쪽에서 들어온다.
- 이전 페이지는 반대 방향으로 움직인다.
- 전체 이동 거리는 컨테이너 폭의 약 6%로 제한하고, opacity를 함께 전환한다.
- 전환 시간은 약 320ms이며 과한 확대와 블러는 사용하지 않는다.
- `prefers-reduced-motion`에서는 위치 이동 없이 즉시 교체하거나 짧은 opacity 전환만 사용한다.

## 반응형과 접근성

- 데스크톱 화살표는 첫 번째·마지막 아코디언 카드의 좌우 가장자리에서 16px 안쪽에 겹쳐 배치한다. 반투명 흰색 원형 표면과 약한 그림자로 이미지 위에서도 조작점을 분명히 하되, 핵심 텍스트와 버튼은 가리지 않는다.
- 모바일은 터치 영역을 최소 44px로 유지하고, 화살표를 하단 페이지 표시 양쪽에 배치해 좁은 화면의 카드 폭을 보존한다.
- 결과 수는 `aria-live="polite"`로 지역 변경을 알린다.
- 화살표에는 현재 이동 결과를 설명하는 한국어 `aria-label`을 제공하고 비활성 상태에는 실제 `disabled` 속성을 사용한다.
- 키보드 포커스가 명확하게 보이도록 기존 브랜드 주황색 포커스 링을 적용한다.

## 컴포넌트와 상태

- 데이터 원본과 필터링은 현재 `HanokStayAccordion`의 `allStays`, `regionFilteredStays`를 그대로 사용한다.
- `pageDirection` 상태를 추가해 이전·다음 전환 방향만 표현 계층에 전달한다.
- 페이지 계산은 현재 `BATCH_SIZE = 7`과 `maxPages`를 유지하되 순환 계산을 제거하고 `0...maxPages - 1` 범위로 제한한다.
- 렌더링 묶음은 `AnimatePresence`의 방향별 variants로 교체한다.
- 외부 API 호출이나 데이터 계약은 변경하지 않는다.

## 검증

- 전체/지역 필터에 따라 결과 수 문구와 페이지 수가 정확히 갱신되는지 단위 테스트한다.
- 이전·다음 버튼의 경계 비활성화와 지역 변경 시 첫 페이지 초기화를 검증한다.
- 페이지 이동 방향에 맞는 모션 상태가 선택되는지 순수 계산 또는 컴포넌트 테스트로 검증한다.
- Playwright에서 데스크톱의 좌우 버튼, 중앙 페이지 표시, 지역별 동적 건수와 모바일 배치를 확인한다.
- TypeScript, ESLint, 전체 Vitest와 관련 Playwright 시나리오를 실행한다.
