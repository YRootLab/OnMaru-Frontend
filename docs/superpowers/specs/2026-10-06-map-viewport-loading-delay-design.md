# 지도 viewport 로딩 안내 지연 설계

## 목적

정상적으로 빠른 viewport 요청에서 `지도 장소를 업데이트하고 있어요`가 순간적으로 나타나는 시각적 깜빡임을 제거한다.

## 동작

- 정보지도 viewport 로딩 시작 후 2,000ms 동안 안내를 숨긴다.
- 같은 요청이 2,000ms를 넘겨 계속 로딩 중일 때만 안내를 표시한다.
- 로딩 완료 또는 실패 시 안내를 즉시 제거한다.
- viewport 오류 UI는 기존처럼 지연 없이 표시한다.
- 로딩이 끝나거나 새 로딩 주기가 시작되거나 컴포넌트가 해제되면 이전 타이머를 정리한다.
- 안내가 표시된 뒤 별도의 최소 노출 시간은 적용하지 않는다.
- API 요청, 기존 마커 유지, viewport limit, 클러스터와 줌 동작은 변경하지 않는다.

## 경계

지연 판정은 표현 계층의 전용 훅이 담당한다. `isViewportLoading` 원본 상태는 데이터 계층과 마커 상태에 계속 즉시 전달되며, 안내 렌더링에만 지연된 boolean을 사용한다.

## 검증

- 로딩 시작 후 1,999ms까지 안내가 없다.
- 2,000ms에 로딩 중이면 안내가 나타난다.
- 2초 전에 완료되면 안내가 한 번도 나타나지 않는다.
- 표시 중 완료되거나 오류가 생기면 즉시 사라지고 오류 UI가 나타난다.
- 타이머 해제 후 상태 업데이트가 발생하지 않는다.
